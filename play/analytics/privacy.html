Optional gameplay analytics

Enable Share gameplay analytics in Folder settings to help improve the game. Expanded reporting is off until you choose it, including if you previously enabled the older session-only reporting. Enabling starts with your next launch. Disabling stops collection immediately and removes the local analytics ID. Do Not Track and Global Privacy Control disable reporting.

Your browser ID

When you launch with reporting enabled, we save a random ID in this browser's local storage. It lets us count unique browser profiles and returning players across sessions without an account. It is a pseudonymous identifier, not proof of a person's identity: another browser, private browsing, cleared storage or an ID reset can count as another player. Several people sharing a browser can count as one. Each launch also gets a separate random session ID.

Use Reset analytics ID in Folder settings to stop the current report and remove the identifier. Your next enabled launch receives a new ID. Resetting or disabling does not erase reports already collected; they expire under the retention period below. Game saves and installations are unaffected.

What is reported

  • Build version, launch time, new journey or resumed save, first rendered frame, loading stages, and fixed failure categories.
  • When you also enable Include crash location and last save details, a detected failure can include the last observed game tile and the latest completed save’s slot, tile, and time. Older saves may have fewer details. Both choices start off.
  • Elapsed and active playtime, background/unfocused/paused time, suspended intervals and render-heartbeat gaps. Heartbeats are not an FPS measurement.
  • Successful automatic/manual saves and loads, save duration, save failures, browser main-thread long tasks when supported, and aggregate native action attempts/rejections by category: movement, interaction, inventory, dialogue, spellbook, combat and developer commands.
  • Whether Trinsic, investigation evidence, reporting to Finnigan and an observed east-gate crossing were reached, and elapsed time when first observed. Progress already present in a resumed save is marked separately.
  • Coarse browser and operating-system families, a small/medium/large viewport category, browser/folder save mode, and native/Exult music selection. We do not send the full user-agent string or hardware specifications.

Active time requires rendered, visible, focused gameplay. Reading dialogue and inventory counts. An unattended foreground game can still count as active; no keypresses, pointer trails or input history are collected. Long suspension gaps are excluded from active time.

Reports are cumulative snapshots every 30 seconds and on lifecycle changes, not a replay of your session. Network failures, blocked requests, crashes and sampling can undercount activity. Reporting never blocks gameplay or saving.

What stays on your computer

Automatic reports omit character names, dialogue, save contents, inventory, game files, folder paths, email addresses, cookies, and fingerprints. Game coordinates are shared only as part of the optional crash details above. The Download crash report button creates a local file with the crash details and the last completed save when available. That downloaded file contains private game data you can choose to share. Cloudflare handles connection information to rate-limit requests. The dataset stores no IP addresses and application logging is disabled.

The project operator can access the private Cloudflare Analytics Engine dataset, retained for up to three months. Published reports contain aggregate counts rather than browser/session IDs. This system currently covers the browser game, not desktop/offline play. Website visit analytics is a separate system.
