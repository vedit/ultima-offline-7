Playtest reporting

The browser playtest can send anonymous usage measurements to the project's Cloudflare service. Turn off Share anonymous playtime and progress in Folder settings to stop reporting. Browser Do Not Track and Global Privacy Control also disable reporting.

Each launch uses a new random session ID, kept only in memory. Reports contain the build version, launch time rounded to seconds, loading success or a fixed failure category, elapsed and active time, and whether Trinsic, investigation evidence, the completed report and the east gate crossing have been observed. Loaded saves can already contain investigation progress.

Active time starts with the first rendered game frame. Hidden or unfocused windows, explicit pause signals and stopped rendering do not count; reading dialogue and ordinary inventory use do. An unattended visible game can count as playtime. These are session measurements, not unique-player counts.

Small cumulative reports are sent every 30 seconds and when the page is hidden or closed. Network failures, browser blocking, abrupt exits and sampling can leave measurements incomplete. Reporting never blocks gameplay or saving.

No character names, chat or dialogue text, saves, inventory, coordinates, game files, paths, email addresses, cookies or persistent player IDs are included. We do not store IP addresses or browser fingerprints in the dataset. Cloudflare necessarily handles connection information and uses the address to limit abusive requests. Worker application logging is disabled.

Cloudflare Analytics Engine retains these measurements for up to three months. Only the project operator has access to the dataset. Your reporting preference is saved locally in this browser. This reporting currently covers the browser build, not desktop/offline play.
